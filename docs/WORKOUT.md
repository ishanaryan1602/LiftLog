# Workout template

Program: **PPL Hypertrophy — Version 1**, 16 weeks, target 1 RIR, schedule Monday Push / Tuesday Pull / Wednesday Legs A / Thursday Push / Friday Pull / Saturday Legs B / Rest. Push days have 11 prescribed working sets; Pull days have 13; Legs days have 12.

Push A/B: Smith Incline Press 2, Machine Flat Press 2, Lateral Raise 2, Single-Arm Triceps Pushdown 3, Cable Crunch 2.

Pull A/B: Lat Pulldown 2, Chest-Supported Row 2, Single-Arm Lat Pulldown 2, Reverse Pec Deck 2, Barbell Curl 3, Reverse Curl 2.

Legs A: DB Shoulder Press 2, Leg Press 2, Leg Curl 2, Leg Extension 2, DB Shrugs 2, Cable Wrist Curl 2. Legs B: DB Shoulder Press 2, Romanian Deadlift 2, Leg Extension 2, Leg Curl 2, DB Shrugs 2, Cable Wrist Curl 2. The template is data-driven and seed-safe.
